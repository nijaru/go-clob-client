# Security Policy

## Reporting a Vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Please report security issues by opening a [GitHub private security advisory](https://github.com/nijaru/go-clob-client/security/advisories/new).

If you cannot use GitHub advisories, contact the maintainer directly using the email address listed on the maintainer's GitHub profile.

Include as much detail as possible: the affected version, reproduction steps, and potential impact. You can expect an acknowledgement within 48 hours.
