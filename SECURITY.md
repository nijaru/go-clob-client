# Security Policy

## Reporting a Vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Please report security issues by emailing the maintainer directly (see your GitHub profile for contact info) or by using [GitHub's private security advisory](https://github.com/nijaru/go-clob-client/security/advisories/new).

Include as much detail as possible: the affected version, reproduction steps, and potential impact. You can expect an acknowledgement within 48 hours.
