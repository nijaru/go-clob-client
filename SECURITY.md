# Security Policy

## Reporting a Vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Please report security issues by opening a [GitHub private security advisory](https://github.com/nijaru/go-clob-client/security/advisories/new).

If you cannot use GitHub advisories, email the maintainer using the address listed on the maintainer's GitHub profile.

Include the affected version, reproduction steps, and potential impact. You can expect an acknowledgement within 48 hours.
